# Kodmoz Code

Rust ile yazılmış minimal bir IDE. **Hızlı**, native ve LSP destekli.

## Markdown Önizleme

- Solda düzenle, sağda canlı önizlemeyi gör.
- Başlıklar, listeler, kod blokları ve bağlantılar desteklenir.
- `Cmd+`` ile terminali aç.

> İyi kod, okunabilir koddur.

```rust
fn main() {
    println!("Merhaba, Kodmoz!");
}
```
